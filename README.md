# 📊 JP Morgan Financial Risk Analysis with Python

## 📌 Project Overview

This project presents a comprehensive financial risk analysis using Python to evaluate customer transaction behaviour, account performance, and potential financial risks. The analysis focuses on transforming raw financial transaction data into meaningful business insights through data cleaning, exploratory data analysis, customer segmentation, statistical analysis, and risk identification.

The objective is to support data-driven decision-making by identifying transaction trends, customer activity patterns, high-risk accounts, and financial anomalies that can assist financial institutions in improving customer management and risk monitoring.

---

## 🎯 Objectives

- Clean and preprocess financial transaction data
- Analyse customer transaction behaviour
- Evaluate account performance and transaction trends
- Build customer profiles based on financial activity
- Detect financial anomalies and high-risk accounts
- Perform statistical hypothesis testing
- Present business insights through visualisations
